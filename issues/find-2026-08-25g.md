## New issues opened (3)

### #133 — Mastery forgetting-risk/review-urgency/readiness never decay (recordAttempt passes now for both lastAttempt and now)
- bug
- `MasteryCalculationService.recordAttempt` passes `DateTime.now()` for both the
  `lastAttempt` and `now` args of the decay/urgency/recency helpers, so
  `daysSinceLastAttempt` is always 0; the elapsed-time decay term is dead code and
  the stored metrics are frozen at "just-studied" values with no recompute path.
- Affected: `lib/core/services/mastery_calculation_service.dart`.

### #134 — getTopicProgress 'lastAttempted' returns wrong attempt (uses unsorted .last on Hive key-ordered list)
- bug
- `topicAttempts.last.timestamp` is wrong because the list follows Hive key order
  (grouped by questionId), not chronological order.
- Affected: `lib/core/services/study_progress_tracker.dart:130`.

### #135 — redistributeMissedWorkload applies first future day's per-day cap to all days (wrong extra minutes)
- bug
- `maxExtraPerDay` is derived from `.firstOrNull` of the per-day caps and reused for
  every redistributed day, under-applying missed workload on larger-target days.
- Affected: `lib/features/planner/services/personal_learning_plan_service.dart`.
